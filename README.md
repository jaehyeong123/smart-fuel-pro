# 스마트 차계부 Pro (Smart Fuel Pro)

스마트폰 모바일 화면에 최적화된 **차량 연비 계산, 주유 기록, 계기판/영수증 AI OCR, 차량 정비 및 소모품 관리 PWA(Progressive Web App)**입니다.

- **🌐 공식 모바일 앱 접속 주소**: [https://jaehyeong123.github.io/smart-fuel-pro/](https://jaehyeong123.github.io/smart-fuel-pro/)
- **🤖 다른 컴퓨터 AI 인수인계 문서**: [AI_HANDOVER_GUIDE.md](./AI_HANDOVER_GUIDE.md)

---

## 🚀 빠른 시작 가이드 (Quick Start)

```bash
# 1. 패키지 설치
npm install

# 2. 로컬 개발 서버 시작
npm run dev

# 3. 빌드 및 GitHub Pages 원클릭 배포
npm run ship
```

자세한 아키텍처, 비즈니스 로직, OCR 전처리 알고리즘, 배포 파이프라인은 [AI_HANDOVER_GUIDE.md](./AI_HANDOVER_GUIDE.md)를 참고하세요.
